# Unitree G1 ロボットの統合

本タスクでは、Unitreeの次世代ヒューマノイドロボット **Unitree G1 (29DoF + Dex3ハンドモデル)** をシミュレーション空間上にロードして制御します。

## 🤖 ロボットアセット情報

G1は、Isaac Labの標準アセット拡張である `omni.isaac.lab_assets` に含まれる公式のUSD/URDFアセットベースを使用します。

*   **自由度 (DoF)**: 29自由度（全身の関節）
*   **エンドエフェクター**: Dex3ハンド（3本指の器用なハンド機構）
*   **制御方式**: 関節位置制御（Rel-Position Drive）。各関節に設定されたPDコントローラを介してアクション命令をトルクへ変換します。

## ⚙️ アクションスケール（Action Scale）の調整

初期のランダム探索段階において、ポリシーがロボットへ出力する命令が大きすぎると、ヒューマノイド特有の激しい自爆（足を滑らせて転倒）を誘発します。

```python
# src/tasks/g1_handover_env.py での設定指針
action_scale = 0.05  # デフォルトからデチューンし、初期探索の過大な挙動を抑制
```

関節の激しい振動（ガタつき）を抑え、生存時間を伸ばすために、低めのアクションスケールから段階的に引き上げるアプローチを推奨します。
