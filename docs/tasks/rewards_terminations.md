# 報酬関数と終了条件の設計

Isaac Lab 6.x の `ManagerBasedRLEnvCfg`（マネージャー駆動型強化学習環境）に準拠した、ハンドオーバータスクの設計パラメータです。

## 🚨 終了条件 (Termination)

初期学習フェーズにおいて、ロボットが数ステップで即座に転倒終端（`robot_fall=1.0`）してしまう問題を回避するため、閾値の設計は慎重に行う必要があります。

*   **`time_out`**: 規定の最大タイムステップ（例: 1000ステップ）に達した場合に正常リセット。
*   **`root_height`**: ロボットのベースリンク（体幹）が指定の最小高さを下回った場合に転倒とみなす。
    *   *初期デバッグ時*: 立ち上がりの勾配を作るため、閾値を `0.3m` 程度まで一時的に緩め、即死を防ぐ。

## 📊 報酬関数 (Reward) の設計マトリクス

「直立の維持」と「ハンドオーバーの成功」を両立させるため、段階的な報酬シェイピングを採用します。

### 1. 姿勢安定・生存報酬（ベースライン）
ロボットを時間切れまで立たせるための最優先報酬です。

| 報酬項目 | 計算関数・アプローチ | 効果 |
| :--- | :--- | :--- |
| **生存報酬** | `func="isaaclab.envs.mdp:alive"` | 時間切れまで耐えるインセンティブを与える |
| **体幹傾きペナルティ** | `func="isaaclab.envs.mdp:root_orientation_error"` | ロボットのピッチ・ロールを垂直に保つ |
| **関節加速度ペナルティ** | `func="isaaclab.envs.mdp:action_rate_l2"` | 関節のガタつきや急激な反転を抑制する |

### 2. タスク報酬（段階的追加）
ロボットが直立安定した後に機能させる、ボトル手渡し用の報酬です。

*   **ボトル把持成功報酬**: Dex3ハンドのグリッパーがペットボトルを適切に挟み、かつ机から浮かせた際にプラス。
*   **ターゲット接近報酬**: ボトルの中心座標と、来場者の手の中心座標の距離（L2ノルム）が縮まるほど指数関数的にプラス。
